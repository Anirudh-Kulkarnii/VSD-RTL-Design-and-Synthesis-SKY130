# VSD RTL Design and Synthesis using SKY130

This repository contains my hands-on work completed during the VSD RTL Design and Synthesis Workshop using Verilog with SKY130 Technology.

## Workshop Topics

- Verilog RTL design
- Testbench development
- Functional simulation
- Icarus Verilog
- GTKWave waveform analysis
- Yosys RTL synthesis
- SKY130 standard-cell technology mapping
- Timing library analysis
- Hierarchical and flat synthesis
- Combinational and sequential optimization
- Flip-flop coding styles
- Gate-level simulation
- RTL versus synthesized behavior
- Synthesis-simulation mismatch
- If, case, for and generate constructs

## Tools Used

- Ubuntu Linux
- Icarus Verilog
- GTKWave
- Yosys
- GVim
- SKY130 standard-cell library
